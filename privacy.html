Privacy Policy — Hanwol Notes Upload

Effective date: October 28, 2026

Who uses this tool

Hanwol Notes Upload is used only by the owner of the Hanwol Notes YouTube channel, on the owner's own computer. It is not offered to the public.

What it accesses

The tool uses YouTube API Services only on the owner's own channel: to upload videos (as private first) and mark them as containing AI-generated media, edit titles, descriptions and playlists, add English titles and descriptions, change the privacy status of the owner's own videos (private / scheduled / public), list captions and remove automatic captions, and read the channel's own view and subscriber counts. It does not collect any information from viewers or from any other person.

How data is stored and shared

The following are stored only on the owner's computer:

  • The sign-in token issued by Google.
  • The channel's own daily view and subscriber counts.
  • A short change log of the tool's own actions (time, video ID, action).

None of this is sent to any server we run, shared with anyone inside or outside, or sold. The tool does not show ads, does not let third parties serve content, and does not use cookies.

If access is revoked, the stored data is deleted within 30 days. If you ask us to delete it, it is deleted within 7 days.

YouTube and Google

This tool uses YouTube API Services. By using it, you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Hanwol Notes Upload's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

In addition to our normal deletion described above, access can be revoked at any time from the Google security settings page: https://security.google.com/settings/security/permissions.

Contact

Questions or complaints about these privacy practices: yanghan55@naver.com
