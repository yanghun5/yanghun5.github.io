Hanwol Notes Upload

"Hanwol Notes Upload" is a small private tool used only by the owner of the Hanwol Notes YouTube channel. It runs on the owner's own computer and uses the YouTube API Services only on the owner's own channel:

  • Upload videos (uploaded as private first) and mark them as containing AI-generated (synthetic) media.
  • Edit titles, descriptions and playlists, and add English titles and descriptions.
  • Change the privacy status of the channel's own videos (private / scheduled / public).
  • List captions and remove automatic captions.
  • Read the channel's own view and subscriber counts.

The tool is not offered to anyone else. It does not access any other person's account or data.
